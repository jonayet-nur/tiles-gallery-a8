# 🧱 TilesGallery

TilesGallery is a modern and responsive web application built with **Next.js** that showcases a beautiful collection of decorative tiles. It is designed with a focus on clean UI, smooth user experience, and scalable frontend architecture.

---

## 📌 Features

- 🖼️ Beautiful tile gallery with dynamic data
- 🔍 Search and filter tiles by name, tags, and style
- 📄 Dynamic routing for tile detail pages
- 📱 Fully responsive design (mobile, tablet, desktop)
- ⚡ Fast performance with Next.js optimization
- 🎨 Modern UI using Tailwind CSS
- 🔄 Reusable and scalable components

---

## 🛠️ Tech Stack

- **Next.js** – React framework for production-ready apps
- **React.js** – UI library
- **Tailwind CSS** – Utility-first CSS framework
- **JSON Server /  API** – Mock data source
- **Vercel** – Deployment platform
